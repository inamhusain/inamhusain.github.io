About

A bit about me.

I work as a Flutter developer on apps used in production. I care about the parts users never notice: smooth scrolling, an offline mode that holds up, payments that don't fail halfway, and crash reports that get fixed before anyone complains.

Outside feature work, I build shared tooling: a utility package and a project template that new Flutter projects start from.
